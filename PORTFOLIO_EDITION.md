# Portfolio Edition

This repository is a sanitized public representation of Nexo, a localhost interface built around the Codex App Server protocol.

The original development package contained local developer documentation, generated protocol schemas and screenshots that exposed a Windows username/path. Those artifacts are intentionally not part of this public repository.

The public edition preserves the parts that demonstrate the engineering work:

- Python stdio bridge to the locally installed Codex service;
- localhost HTTP boundary;
- Host / Origin / token validation;
- workspace scoping;
- attachment validation;
- Conversation / Work modes;
- approvals and execution controls;
- model/reasoning controls;
- usage/account UI hooks;
- responsive browser interface.

No API key, Codex auth token, conversation database, log file or private workstation path is included.
